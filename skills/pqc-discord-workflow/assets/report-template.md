### 해석과 한계

평균의 절대·상대 차이, 회차별 변동, 실패율, 실제 허용치와의 관계를 설명한다. 서명 크기 증가와 전체 요청 지연의 관계는 관측한 환경에 한정한다. “차이가 작다”는 결론을 미리 정하지 않는다. 비교 조건이 다르거나 원본이 실행되지 않았으면 그 이유를 적고 비교 완료로 쓰지 않는다.

## 7. 전체 프로젝트 ZIP과 재빌드

- 제출 ZIP 파일명·크기·SHA-256:
- 전체 프로젝트 구성과 필수 자산·의존성:
- 제외한 파일과 이유 / 비밀 값·불필요한 캐시 점검 결과:
- 새 폴더에 최종 ZIP을 푼 경로·환경:
- 수신자가 따라 할 의존성 준비·빌드·실행·테스트 명령:
- 최종 ZIP으로 실행한 빌드·필수 시험 결과와 종료 코드:
- ZIP 내부 파일 목록·해시의 확인 근거:

최종 ZIP 재빌드 로그의 필요한 부분을 아래에 포함한다. 검증 후 ZIP을 수정했다면 새 해시와 재검증 결과로 갱신한다. 보고서 자신의 해시를 내부에 넣으려고 순환 갱신하지 않는다.

## 8. 사용한 AI 작업 프롬프트

### 실제 사용자 작업 지시와 추가 요구

공유 가능한 원문과 작업 중 추가된 요구를 순서대로 기록한다. 공개하면 안 되는 값은 가리고 가린 사실을 표시한다. 확보하지 못한 과거 프롬프트를 만들어 넣지 않는다. 시스템 지침·내부 추론·다른 대화는 포함하지 않는다.

### 공유용 재현 프롬프트

같은 문제·소스·제약과 검증 절차를 다른 사람이 재현할 수 있도록 정리한 프롬프트를 기록한다. 이 항목은 실제 입력 원문과 구별한다.
